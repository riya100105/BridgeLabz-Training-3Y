ASSIGNMENT 1 — JavaScript Solutions

This folder contains one JavaScript solution file for each of the 10 questions.

How to run:
1. Extract the ZIP file.
2. Open a terminal in this folder.
3. Run a file with Node.js, for example:
   node Q1_Personalized_Login_Greeting.js
4. You can also paste a file's code into your browser Developer Tools Console.

All solutions use core JavaScript only. Sample values are provided where input is required;
change those values in the file to test different outcomes.

ASSIGNMENT 7 - JAVASCRIPT

Contents:
- index.html: home page with links to all 9 questions
- q1.html to q9.html: separate demonstration pages
- js/q1.js to js/q9.js: separate JavaScript files for each question
- css/style.css: shared styling

How to run:
1. Extract the ZIP file.
2. Open the Assignment_7 folder.
3. Double-click index.html, or open it in a browser.
4. Select any question card to test that task.

Note:
Question 5 loads its six sample gallery photographs from Unsplash, so an internet
connection is required for those images to appear. All functionality is written
using core JavaScript without frameworks.

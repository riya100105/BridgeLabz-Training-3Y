ASSIGNMENT 8 - JAVASCRIPT

Files:
Q1 to Q9 contain the solution for each question in a separate JavaScript file.

How to run:
1. Open the folder in Visual Studio Code.
2. Open the terminal in that folder.
3. Run a question using Node.js, for example:
   node Q1_Student_Result_Processing.js
4. Replace the filename with the required question file to run another solution.

You can also paste each file's code into the browser console.

Notes:
- Q1 uses these grade ranges: A = 90 and above, B = 75-89, C = 50-74, F = below 50.
- Q6 treats stock of 5 or fewer as low stock.
- Q5 uses an example fare rate of Rs. 10 per kilometre.
- All examples use sample data and can be edited as needed.

- Q9_Shopping_Cart_Total.js

Running JavaScript-only questions:
1. Open the folder in VS Code.
2. Open a terminal and run e.g. node Q1_Ecommerce_Product_Manager.js.

Running form/DOM questions:
1. Keep each HTML file next to its matching JS file.
2. Open the HTML file in a browser (or use VS Code Live Server).
3. Enter values and submit the form.

Note: DOM-based questions (Q2, Q4, Q5, Q7, Q8) must run in a browser, not directly with Node.js, because they use document and HTML forms.
